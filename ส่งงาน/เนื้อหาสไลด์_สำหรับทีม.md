## 1. หน้าปก
- **Bloom Craft** – AI นับดอกไม้ บอกชนิด บอกสี → สร้างช่อดอกไม้
- INT182 กลุ่ม 1 · ชื่อสมาชิก

## 2. ระบบทำอะไรได้ (โจทย์ข้อ 2: features)
- ถ่าย/อัปโหลดรูปดอกไม้ → ระบบ **หาดอกทุกดอก + นับจำนวน**
- บอก **ชนิด** 4 ชนิด: rose, tulip, sunflower, daisy (ชนิดอื่น = unknown)
- บอก **สีของดอก** จากพิกเซลของตัวดอกจริง (ไม่ปนพื้นหลัง)
- **กันรูปที่ไม่ใช่ดอกไม้จริง**: การ์ตูน/เกม/ภาพวาด ไม่นับ
- ส่งผลต่อให้ **เว็บ Bloom Craft** เลือกสไตล์ + ภาชนะ → **เจนรูปช่อดอกไม้จริง** โดยใช้รูปดอกที่ตัดจากรูปถ่ายเป็นตัวอ้างอิง
- ส่งออก `bouquet.json` + รูปดอกตัดพื้นหลัง (PNG พื้นใส)

## 3. Pipeline (โจทย์ข้อ 1)
```
รูป → [1] ดอกไม้จริงไหม? → [2] หาดอก → [3] ตัดกรอบ/กรองที่ไม่ใช่ดอก → [4] บอกชนิด → [5] บอกสี → [6] เว็บ / bouquet.json → [7] เจนช่อดอกไม้
       CLIP ViT-B/32        SAM 3         CLIP                   BioCLIP 2 + head      mask ของ SAM 3
                                                                 (ที่เราเทรนเอง)
[7] เจนช่อดอกไม้: Realistic Vision 5.1 (Stable Diffusion 1.5) + IP-Adapter Plus (prompt + รูปดอกจริงที่ตัดพื้นหลังเป็นตัวอ้างอิง)
```
- ขั้นที่เราเลือก/เทรนและวัดผลเทียบ: **[2] หาดอก** และ **[4] บอกชนิด**
- SAM 3 (Meta) + BioCLIP 2 เป็นโมเดลสำเร็จรูป · **เราเทรน**: YOLO11 (หาดอก), YOLO11n-cls และ head บน BioCLIP 2 (บอกชนิด)

## 4. เทียบโมเดลหาดอก (ขั้น [2])

## 6. เทียบโมเดลบอกชนิด (ขั้น [4]) + confusion matrix (โจทย์ข้อ 4)
Test 672 รูป

| โมเดล | Accuracy | Macro-F1 | ดอกที่ไม่เคยเห็น → other |
|---|---|---|---|
| BioCLIP 2 zero-shot (ไม่เทรน) | 89.3% | 0.899 | 98.3% |
| YOLO11n-cls (เราเทรน) | 93.1% | 0.927 | 90.8% |
| **BioCLIP 2 + head (เราเทรน)** ✓ ใช้จริง | **97.3%** | **0.973** | **99.2%** |

- รูป: `results/species_eval_v2/` → `cm_BioCLIP_2_plus_head.png` (ตัวที่ดีที่สุด), `cm_BioCLIP_2_zero-shot.png`, `cm_YOLO11n-cls.png`, `compare.png` (กราฟแท่ง)
- head = ชั้น Linear ชั้นเดียว (768 → 5) ต่อท้าย BioCLIP 2 ที่ไม่ได้แก้ตัวมันเอง เลือก weight decay ด้วย Val
- อ่าน confusion matrix: zero-shot ทายดอกจริงเป็น other บ่อย (กุหลาบ 21, เดซี่ 17) · YOLO สับสนกุหลาบ↔ทิวลิป 12 รูป · head ผิดแค่ 18 จาก 672

**ทำไมต้อง v2 (เพิ่ม Oxford 102)** – เทียบ head รุ่นแรก (other = แดนดิไลออนอย่างเดียว) บน Test เดียวกัน

| | head v1 | head v2 |
|---|---|---|
| Accuracy รวม | 82.6% | **97.3%** |
| ดอกไม่รู้จัก → other | 7.5% | **99.2%** |
| เฉพาะ 4 ชนิด | **98.6%** | 96.2% |
